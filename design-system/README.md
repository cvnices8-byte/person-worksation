# 研习台界面方向

依据 UI UX Pro Max 的 minimalism-and-swiss-style 检索结果：面向长期学习的极简工作台，使用几何网格、明确层级、细线与留白。首次综合检索推荐的营销落地页结构不适用于本产品，未采用。

- 品牌：翻开的书页与专注圆点，SVG 图标保持 1.65px 描边，导航有可读名称。
- 色彩：纸白背景、深绿主操作；原有科目色保留为辅助定位。错误和成功仍有文字说明。
- 字体：本地中文无衬线用于操作，宋体用于标题；计时数字使用等宽数字特性，不依赖外部字体服务。
- 交互：主要操作至少 44px；支持键盘焦点、手机安全区域、减少动态效果。
- 番茄钟：25/50 分钟专注、5/15 分钟休息。按截止时间计算剩余时间，暂停与刷新可恢复，不要求页面持续前台运行。
- 学习记录：仅完整专注轮次可由用户确认写入；休息不计入学习；固定轮次 ID 防止重复记录。
- 状态提示：只播报开始、暂停、完成和保存等事件，不每秒播报数字。
