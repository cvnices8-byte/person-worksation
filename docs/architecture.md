# 架构决策

## 边界

- 网站负责学习、练习、记录和统计。
- Obsidian负责目标、规划、复盘和决策。
- 首版以单向 Markdown 导出连接两端。

## 首版形态

- 纯静态 PWA，可由 GitHub Pages 托管。
- IndexedDB 存储个人数据。
- 无服务端、无登录、无第三方运行时依赖。
- 所有敏感数据与发布产物分离。

## 数据对象

- Task：当天可完成的学习结果。
- Session：一次有效学习记录。
- Paper：专业理解与英文输出组成的论文学习包。
- Health：每日身体状态记录。
- Review：按周聚合后导出的 Markdown，不在网站内作长期规划。

## 后续扩展边界

AI 密钥、用户账户、跨设备同步和音频文件必须进入服务端或专用存储，不能直接加入 GitHub Pages 前端。
