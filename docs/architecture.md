# 架构决策

## 边界

- 网站负责学习、练习、记录和统计。
- Obsidian负责目标、规划、复盘和决策。
- 首版以单向 Markdown 导出连接两端。

## 首版形态

- 纯静态 PWA，可由 GitHub Pages 托管。
- IndexedDB 存储个人数据。
- 无服务端、无登录、无第三方运行时依赖。
- 所有敏感数据与发布产物分离。

## 数据对象

- Task：当天可完成的学习结果。
- Session：一次有效学习记录。
- Paper：专业理解与英文输出组成的论文学习包。
- LearningPlan：年度阶段、课程单元进度与自动排课依据。
- DailyPaperFeed：从公开论文源拉取并按天缓存在本机；网络失败时回退到本机精选。
- CodingPractice：每道练习的代码草稿与完成时间；代码仅存当前浏览器，可单独下载为 `.py`。
- EnglishPractice：词汇复习间隔、短课活动、日常表达草稿、跟读完成状态和论文英语草稿。
- Health：每日身体状态记录。
- Review：按周聚合后导出的 Markdown，不在网站内作长期规划。

## 后续扩展边界

AI 密钥、用户账户、跨设备同步和音频文件必须进入服务端或专用存储，不能直接加入 GitHub Pages 前端。

## 外部内容降级

- 每日论文优先读取 Hugging Face Daily Papers 的公开 JSON 接口，并按 AI、数据科学和财务关键词分类。
- 成功结果按日期写入 IndexedDB，避免重复请求。
- 在线推荐会与本机领域精选合并，确保财务等低频领域不出现空栏。
- 接口、网络或跨域策略不可用时，显示本机基础论文精选；学习记录不受影响。

## 数据与 AI 学习台

- 理论主线和课程资源属于版本化静态内容，便于在 GitHub 上审阅与更新。
- 课程链接优先使用官方文档、课程官网或原作者仓库。
- 代码编辑区不在浏览器内执行任意 Python；当前阶段只负责练习定义、草稿管理、提示生成和文件导出。
- “AI 教练提示”要求模型优先给提示与测试，不直接代写完整答案，以保留训练价值。

## 英语训练台

- 每日训练路径按建议时长显示独立进度，不自动写入全局学习时长，避免与手动学习记录重复计算。
- 语法短课同时提供英文题干、中文翻译和答题后的中文语法说明；翻译用于确认理解，不替代英文作答。
- 日常用语按沟通场景组织，每个场景包含核心句、替换结构、两种变体和用户自己的表达。
- 词汇评级决定下一次到期时间；首版使用透明的固定间隔，后续可升级为基于召回结果的调度模型。
- 系统语音只使用浏览器的 `SpeechSynthesis`；不请求麦克风权限、不存储录音。
- 论文英语直接使用当日推荐论文，结构化草稿与完成状态存入 IndexedDB。
