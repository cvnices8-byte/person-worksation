# 研习台 · Personal Workstation

[在线体验](https://cvnices8-byte.github.io/person-worksation/) · [架构决策](docs/architecture.md)

一个面向长期学习的、本地优先的个人工作站。它把“今天做什么、怎么练、留下什么证据”集中到一个静态网站；将长期目标、规划与复盘通过 Markdown 交给 Obsidian。

> 当前是可用的首版：没有账户、没有服务端、没有云同步。学习、健康与草稿数据默认只保存在当前浏览器。

## 当前功能

- 每日学习时间尺：1–12 小时可调，按 30 分钟调整；支持 3h / 4h / 6h / 8h 一键预设，刷新后保留。
- 番茄钟：25/50 分钟专注与 5/15 分钟休息；暂停、刷新与收起面板后仍能恢复。完整专注轮次需用户确认后才会记入学习时长，休息不计入。
- 根据本周缺口与当前课程阶段生成今日学习计划
- 一年四阶段学习路线与可勾选课程树
- 数据科学与 AI 学习台：六阶段理论主线、官方课程索引和可验证阶段成果
- 8 个内置 Python / AI 编程实验，支持本机草稿、完成状态、`.py` 下载与 AI 教练提示
- 英语六阶段课程，并与论文精读和英文复述联动
- 英语训练台：每日 60 分钟路径、带中文翻译和语法说明的专业短课、连续学习与即时反馈
- 16 个数据科学、AI、财务语境词汇，支持到期复习、熟悉度分级和系统发音
- 12 组日常沟通场景，支持句型替换、系统发音和个人表达草稿
- 英语跟读句库与论文摘要结构化改写，草稿和进度仅保存在本机
- 参考“人人都能用英语 / Enjoy”的回声跟读、精听听写即时校对和自选材料自动切句
- CPA 学习工作台：未来 52 周路线、六科章节地图、2026 题型分值参考、示范题库、错因分类与 AI 辅导提示
- 考公考编训练台：一年路线、行测五模块、限时示范题、七类解题视角、申论草稿与批改提示、错题诊断
- 数据科学与 AI、CPA、考公、英语、求职维护、复盘的周配额
- 今日任务与完成状态
- 学习时长记录
- 论文专业理解与英文输出学习包
- AI、数据科学、财务三领域论文筛选，结合 Hugging Face Daily Papers 与离线精选
- 体重、腰围、睡眠、步数和训练记录
- Obsidian 周复盘 Markdown 导出
- JSON 完整备份与恢复
- IndexedDB 本地数据存储
- PWA 离线外壳

## 使用闭环

```text
设定今日目标 → 开始专注 → 学习 / 练习 → 记录可验证结果 → 周复盘导出
```

- 学习站服务于每天的执行、训练与记录。
- Obsidian 服务于长期规划、复盘与决策留痕。
- 每个课程、题目或笔记应尽量落到一次作答、表达、代码或复盘，而不只是收藏资料。

## 首版复盘

### 已验证的选择

- 纯静态 PWA 足够承载个人学习执行与本地数据记录，部署和维护成本低。
- CPA 与行测使用章节/知识点地图，比长列表更容易看到当前进度与下一步。
- 英语与论文在同一工作流中，可以把专业阅读转化为英文输出。
- 可调目标与番茄钟让“每天学习 6 小时”变成可根据精力和日程调整的计划，而不是固定口号。

### 当前边界与下一步

1. 教材、题库与知识库还未批量接入；后续只接入用户自有或明确授权的内容。
2. 代码编辑器只负责练习定义、草稿管理、提示生成与文件导出，尚不执行任意 Python。
3. 当前 AI 辅导功能只生成结构化提示词；批改、口语和论文反馈需要用户在自己选择的模型中使用。
4. 跨设备同步、音频存储、账户与 API 密钥需要服务端或专用存储，不应直接加入 GitHub Pages 前端。

## 技术结构

- 纯 HTML、CSS、JavaScript；没有第三方运行时依赖。
- IndexedDB 保存任务、学习记录、论文、健康、各模块练习状态与设置。
- Service Worker 提供 PWA 应用外壳和离线回退；新版会优先检查线上页面，避免长期读取旧缓存。
- Hugging Face Daily Papers 提供公开论文源；网络不可用时回退到本机领域精选。

## 本地运行

项目没有第三方运行时依赖。需要通过本地 HTTP 服务器打开，不能直接双击 `index.html`，因为浏览器会限制 ES Modules 和 Service Worker。

```bash
npx serve .
```

或者：

```bash
python3 -m http.server 4173
```

打开 `http://localhost:4173`。

## 验证

浏览器回归测试覆盖学习目标保存、今日计划、CPA/行测/英语交互、论文离线回退、健康记录、移动端布局、加载恢复，以及番茄钟的暂停与刷新恢复。

```bash
TEST_URL=http://127.0.0.1:4173 node tests/smoke.cjs
```

先按上一节启动本地服务。测试脚本需要已安装 Playwright 与 Chromium；`tests/focus.cjs` 额外验证番茄钟完成、学习记录防重和响应式布局。

## GitHub Pages

仓库已包含 `.github/workflows/deploy.yml`。推送到 `main` 后：

1. 在仓库 `Settings → Pages` 中选择 `GitHub Actions` 作为发布源。
2. 打开 Actions，确认 `Deploy to GitHub Pages` 成功。
3. 访问 Actions 输出的 Pages 地址。

## 隐私模型

- 学习、健康和论文记录默认只保存在当前浏览器的 IndexedDB。
- 个人数据不会随网站部署到 GitHub。
- 更换设备或清理浏览器前，请在“复盘”中导出完整 JSON 备份。
- 不要把导出的备份、录音、简历或 API 密钥提交到仓库。
